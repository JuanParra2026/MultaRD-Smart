# 📘 Manual de Usuario | MultaRD Smart

## 1. Introducción
MultaRD Smart ofrece una interfaz gráfica intuitiva orientada a facilitar la consulta, emisión simulada y seguimiento de infracciones viales.

## 2. Requisitos Previos
- Navegador moderno (Google Chrome, Microsoft Edge, Mozilla Firefox o Safari).
- Resolución recomendada: 1024x768 o superior (diseño totalmente responsive).

## 3. Guía de Operaciones
1. **Cambio de Tema Visual**:
   - En la barra superior derecha, pulse el botón de sol/luna para alternar entre **Modo Oscuro** y **Modo Claro**.
2. **Emisión de Multas**:
   - Campos requeridos: Conductor, Cédula / Licencia, Placa, Infracción y Monto Base.
   - El sistema calculará el total en pesos dominicanos (RD$) aplicando las reglas de negocio.
3. **Impresión de Comprobante**:
   - Al abrir un acta, use el botón "Imprimir Comprobante" para enviarla a la impresora física o guardarla como PDF con estilos de impresión optimizados.
